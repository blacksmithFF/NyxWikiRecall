# Drafts

Pages waiting for approval live here. The folder name starts with `_`, so NyxWikiRecall never
shows these pages to the agent (`skip.hidden = yes` in `questions.txt`).

Write a draft exactly as the finished page will look, at the path it will have, for example
`_drafts/people/sam-rivera.md`. To publish it, move it to `people/sam-rivera.md`, add it to
`index.md`, and note the move in `log.md`.
