# Log

One entry per change to the wiki, newest last. Keep the heading format the same, so the log
stays easy to search.

```
## [YYYY-MM-DD] <what happened> | <subject>
- Source: <which day or record>
- Changed: <pages edited, created, drafted>
- Open: <questions left for a person to decide, or "none">
- Restore point: <commit id or backup folder, or "none">
```

## [YYYY-MM-DD] created | starter wiki
- Source: the NyxWikiRecall starter template
- Changed: SCHEMA.md, index.md, log.md, four empty folders
- Open: none
- Restore point: none
